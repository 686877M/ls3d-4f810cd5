# Working principles (the "thinking brain" for every project)

1. **Information first (BIM, ISO 19650).** Every element carries class, family, material, quantity, cost, make, level of detail and a source. A model without data is a drawing.
2. **One source of truth.** Quantities, cost, schedule, drawings and checks come from the same element list, so a change flows everywhere.
3. **Project management.** Scope, time, cost and risk are tracked together: CPM schedule, earned value, scenarios, Monte Carlo, risk register (ISO 31000).
4. **Consultant and contractor views.** The consultant checks design, codes, clashes and calculations; the contractor plans methods, resources, cost and safety. The tool offers both through roles.
5. **Data validation before decisions.** Missing prices, outliers in quotes, loops in logic, elements without data and units mismatches are flagged before a number is used.
6. **Best price by analysis, not by guess.** Compare quotes by item, flag outliers against the median, evaluate the basket, apply the lowest verified prices.
7. **Honesty.** Values come from drawings, calculations, vendor data or the user. Anything else is an assumption, marked and sourced. Untested exports are said to be untested.
8. **Continuous learning.** Lessons are recorded in the project; sources are linked, never copied from memory.
9. **Sustainable development.** Small modules, a documented extension path, tests that click every command, and a release note of known limits.
