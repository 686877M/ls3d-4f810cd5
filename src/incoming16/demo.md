## Known issues (read these)
1. **lazygl.js bug (not mine, breaks the 3D view):** the Proxy `set` trap writes every key to the real renderer, so Render Studio's `renderer.render = ...` install/uninstall leaves `real.render` = the lazy wrapper, which calls itself: after ANY render job `Maximum call stack size exceeded` forever and the live view stops (0 frames). Reproduced on the pristine merged build with `tpNew('house2')` + `TOX.render({kind:'still',preset:'draft'})`. One-line fix in `lazygl_fix.diff` (`if(k in o){ o[k]=v; return true; }` first in `set`). With it: frames continue, no error. Chapter 12 triggers it, so merge this fix together with the demo.
2. R.X canvas clicks (walls/doors/windows/column) depend on the 3D view size; door/window/floor/column retry up to 3 times; one earlier run failed 'Column added' once without retry.
3. The default speed is 1x and the demo is long at 1x (not timed end to end; 4x full run = 5.6 min). Owner feedback not yet applied: calmer pace, caption under the cursor, exact geometry and phase order (waiting for incoming19 phase map).
