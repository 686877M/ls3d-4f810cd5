## Why it froze / stopped (root causes found in the old code)
1. `xaHandle` (c_agent2.js) returns after the FIRST thing it recognises: "open GIS and go to Maadi street X" = opens the tab, then returns. Nothing ran the rest.
2. Every mission step is chained on one global promise `XMS.lock` (c_mission.js) with no timeout: one step that never resolves blocks every later step and the cursor sits still ("freeze"). Step-by-step mode (`xto-msstep`) also parks the cursor on a confirm bubble.
3. The agent mic (`xaVoice`) used `interimResults=false` and the browser's own end-of-speech: no live text, no silence timeout, long listening; text shown only in the small chat line.
4. Place search existed only as the G.X search box (`gmSearch`), never reachable from the agent.

## What the 4 chunks do
- **ag5_widget.js**: floating widget (id `#ag5w`, z 99980, in `body`, so tab/layout switches never remove it; re-raised on every `wtSwitch`). Draggable, snaps to the nearest corner. Large transcript `#ag5txt` (16 px, grows up to 40 % of the screen, scrolls, editable; Enter sends). Status pill: listening / thinking / doing k of n + step / done / failed: reason. Plan list with ✓ ✗ per step and the result or reason. Push-to-talk (click = listen once, hold = talk while held) and hands-free (listens again after each request, waits for TTS to end). End of speech: silence timeout 1.2 s (0.4-5 s), max 20 s (3-60 s), "nothing heard" after 8 s; then the text sits in the box with a 1.5 s countdown that any click/edit cancels (or auto-send off: press Send). STT: browser speech recognition with live interim text; if the AI pane STT is bridge / local Whisper / server, a level VAD + `aiTranscribe` (so sttlocal.js still applies). Stop button and Esc stop listening AND the running steps. Alt+J toggles. Replaces `xaVoice` (the agent panel mic now opens the widget).
- **ag5_exec.js**: wraps `xaHandle`. Request -> clauses (splits on ثم / بعدين / وبعدين / then / ; and on "و"/"and"/comma when followed by a verb; commas inside a place name are kept) -> explicit steps (shown before running). Missing tabs are inserted (place -> G.X, line -> C.X, wall -> R.X). Steps run one by one, each awaited until its visible result (tab current AND drawn, map moved, value changed) with timeouts (tab 8 s, step 15 s, place 20 s, old agent 90 s). A failed step: reason shown + spoken summary; later steps still run; if later steps depend on it (tab / place) it asks Retry / Skip / Stop. Cursor `#ag5cur`: requestAnimationFrame tween with a timer fallback (background tabs pause rAF), cancelable. No busy waits. Context `AG5.ctx` {tab, obj, place}: "it/that" = last object made or touched, unless you selected another one yourself (your selection wins). New requests during a run are queued. Questions (`XAS.q`) and anything not understood go to the old chain unchanged (rules / free models / Claude), so existing behaviour stays.
  Learning: successful requests -> steps stored in IndexedDB `xto-ag5` (this computer only, max 200, never in the project package, deleted by "Forget all" / command `ag5_forget` and by the privacy close-out wipe, which deletes all IndexedDB databases). An exact learned phrase runs its stored steps (marked "learned"); typing shows the closest learned phrases as chips (no network).
- **ag5_geo.js**: place -> G.X with a marker. Order: demo places from gm_ui.js `GMPLOTS` (nc1/nc2/nc3/sz/alx, "التجمع الخامس", "الشيخ زايد", "سموحة": no network), typed coordinates, then Nominatim: one request at a time, >= 1.1 s apart, cache (memory + sessionStorage `xto-ag5geo`, 100 entries), max 3 tries (drops the most specific part and SAYS so: "street 9 not found, showing Maadi"), Egypt named -> `countrycodes=eg`, `accept-language=ar,en`, attribution in the widget (Nominatim, © OpenStreetMap contributors, ODbL). Search only on a final request, never while typing (Nominatim policy). Sensitive mode (`PRIV.cfg.sensitive` and not `PRIV.cfg.geo`): blocked before any request, reason shown, "Allow and retry" button sets the existing privacy switch `PRIV.cfg.geo` (same as the privacy panel) and is logged. The request still goes through `window.fetch`, so the privacy.js gate applies too.
- **ag5_ops.js**: tab open / close, undo, zoom in/out (G.X map zoom, C.X view, else XC `zin`/`zout`), zoom to it (`zsel` / map / C.X), draw line N m (C.X), draw wall N m (R.X), place marker (G.X), delete it, vertical / horizontal, rotate N°, move N m right/left/up/down (Egyptian "شمال" = left), set length, set height (R.X walls/columns), measure (line/wall length, distance between the last two map markers, else opens the tab's measure tool: G.X measure, C.X `c_dim`, 3D `m_dist`), any XC command by name. Each change = one undo step (`xaTxn`). Every action is logged (`xaLog` kind `ag5` -> `xto-aglog`, and `AG5.log`).

Commands: `ag5_open`, `ag5_listen`, `ag5_forget`, all with XDESC (en/ar). Settings key `xto-ag5ui` (UI only). Nothing built at page start: no DOM, no style, no IndexedDB, no request (tested); only one keydown listener (Alt+J).

## Honest limits / not tested
- **Real microphone and real speech** (Web Speech in Chrome / Edge, Whisper paths): not tested; a fake recognizer was used. Safari/Firefox have no Web Speech -> the VAD + STT server path, not tested with a real mic.
- **Real Nominatim**: not called (mocked). Arabic street names in Egypt are often missing or spelled differently in OSM; the fallback then shows the district and says so. Usage policy: OK for a person typing/saying a few places; NOT for bulk or for a public site with many users (then run your own Nominatim or a paid geocoder).
- **Understanding** is rule-based for these commands (verbs, numbers, units, directions in Egyptian Arabic and English). Free-form requests outside them go to the old chain; their quality depends on the chosen AI model (free chain / Claude) and is not changed here.
- C.X has no unit setting: 1 drawing unit is taken as 1 m (the result says so). "Vertical/horizontal" is in plan (R.X walls) / drawing axes (C.X). Height only for R.X walls/columns.
- "Stays across windows" = across T.O X tabs and its internal windows (one page). A separate browser window opened by the app is a new page: the widget is not mirrored there.
- The old mission cursor/dock (c_mission.js) is unchanged and still used by old-chain requests; `XMS.lock` without timeout remains there (not edited, shared file).
- Settings key `xto-ag5ui` is not in the privacy KEEP list, so a close-out wipe resets widget position/mode (no project data in it). Optional one-word change in privacy.js / build.py KEEP if the owner wants it kept.
