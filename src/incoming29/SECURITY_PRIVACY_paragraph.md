**Maps and your location.** Every map tile request tells the tile provider (OpenStreetMap, Esri, CARTO, NASA GIBS, EOX and the other hosts in the layer catalogue) which place you are viewing, and your IP address; geocoding (Nominatim) and elevation (Open-Meteo) send the place name or coordinates. Nothing is requested until you open G.X or F.X. In **Sensitive project mode** no map tile host is contacted until you approve that host in G.X > Maps (a coordinate grid is shown instead; the S.X Geo imagery and embedded OSM map are off too), and search / elevation stay blocked by the existing "map lookups" rule. **Offline grid** mode makes no map request at all. API keys for map providers are kept in the browser tab only (session storage), never saved, never part of the project package. The approved-host list, layer dates, opacities and any custom tile server URL are project settings (`xto-gm`) and are removed by a project wipe. Layer licence flags are informational, not legal advice. Demo places are approximate coordinates, not surveyed parcels, and carry no owner or address data.
