# MOD-LNK colour-linked windows (c_link.js + c_link2.js)
Integration: insert at END of chain, after c_templates.js and c_outputs.js: `+rd('c_link.js')+rd('c_link2.js')` in patch_v3.py. No other chunk edited.
Design: colour in WX.lay[id].lk (saved by wxSave); per-tab layouts carry it as 6th item of the wtSnap row (wtSnap/wtApply wrapped). Bus LK.emit(kind,payload,src) -> only other OPEN windows of src colour. Changes made inside other windows are detected by a 120 ms poll (RV.sel, RV.lv, PS.dd, DAY, PS.sel, IS.sel, ifV.sel, cameras); receivers re-snapshot after applying (no echo); cameras only emit from a pane touched <1.5 s ago.
Receivers: element -> BOQ (rows matched by kind words, outlined), issues (IS.fEl filter + chip, isRender wrapped), IFC (GlobalId if R.X el has .guid, else class; select+isolate), Gantt/P6 (src 'rx' acts whose name starts with the RXP work item of the kind; narrowed by level name/a.lv; PS.sel = first, all in LK.hit.sched), R.X windows (id, guid, or first element of kind on level). level -> plan, section (redraw only), browser, IFC storey filter. time -> Gantt/P6 PS.dd, 4D DAY/timeline. view -> view3d <-> pane:ifcview. selection -> R.X (first id) / IFC.
Render Studio: not present; register with LK.reg3d(winId,get,set) ({pos:[x,y,z],tgt:[x,y,z]}) and LK.on('time',winId,fn).
Open as window: TOXAPI.openAsWindow(type,rect), types in LK.MAIN (+gantt,dc,ifc,issues,plan,section,render); menu group in mnOpen (mn_tabs) and tab right-click item. TOXAPI.link(a,b,colour), TOXAPI.unlink(id), TOXAPI.lk. Agent: xaPre wrapped; link verb + >=2 of schedule/model/BOQ/IFC/issues/plan/section words; XCMD lk_sched.
Note: the pane map in c_mission is XMSPANE (not MSPANE) and some ids there do not exist; LK.MAIN is its own map.
